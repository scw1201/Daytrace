# Daytrace

**Your work is already in the conversation.**

**工作上下文已经在对话里，写日报不用再回忆一遍。**

用 agent 写代码、做研究、改方案，任务、过程和结果都留在工作对话中。Daytrace 是一个开源 agent skill：从这些记录中整理当天成果，按你的模板生成自然、清楚、保留关键数据的日报。

```text
用 Daytrace 写今天的日报，面向团队，按项目总结成果和下一步。
```

## 为什么用 Daytrace

- **少一步整理**：优先使用当前会话，或在宿主允许时自动查找项目中的工作会话。无需把复制 session ID 作为默认操作。
- **先说成果，再讲细节**：完成事项和总结思考都先给总体结论，再按主题展开，避免流水账。
- **面向读者筛选细节**：领导汇报突出交付、影响与风险，工程细节按需展开。
- **你的模板，你的读者**：接受文本、Markdown、示例日报或截图中的栏目；适配个人、团队、主管、客户和导师。
- **只保留有意义的数据**：优先交付、进度、质量、效率和影响指标；省略无助于判断成果的文件数、提交数和操作次数，不强行量化。
- **有依据的进度**：区分完成、尝试、阻塞和计划，合并重复记录；保留关键结论的来源位置，不虚构工时。
- **可配合定时任务**：让宿主调度器定期调用同一个 skill，按保存的项目范围和模板生成草稿。

## 安装

### Codex：项目级安装

在目标项目目录执行：

```sh
git clone https://github.com/scw1201/Daytrace.git /tmp/daytrace-source
mkdir -p .agents/skills
cp -R /tmp/daytrace-source/skills/daytrace .agents/skills/daytrace
```

若目标目录已存在，请先检查已有版本再更新。也可以让支持安装 skill 的 agent 从本仓库安装 `skills/daytrace`。

### 其他 agent

将 `skills/daytrace` 安装到宿主支持的 skill 目录，或让 agent 读取其中的 `SKILL.md`。会话读取和发现方式取决于宿主；当前尚未完成其他平台的兼容性验证。

## 用法

**当前会话**

```text
用 $daytrace 总结这个会话今天的工作。
```

**当前项目**

```text
用 $daytrace 写这个项目今天的日报，面向主管，突出产出和阻塞。
```

**指定日期与范围**

```text
用 $daytrace 写 2026-10-13 的日报，时区 Asia/Shanghai。
只包括当前项目，按项目主题汇总，不列工具操作过程。
```

**自定义模板**

```text
用 $daytrace 写今天的日报，按下面四栏：
要点和产出 / 总结和思考 / 目标和计划 / 有效时间。
先总结，再展开；保留重要数量，工时没有记录就留待补充。
```

可以提供自己的示例日报或模板截图。语言跟随请求，不预设中文或特定职业。也可以指定一个或多个会话 ID、链接或导出的记录，作为精确范围。

## 如何读取工作记录

```text
确定日期与范围 → 读取会话 → 提取事实 → 合并重复成果 → 按模板写日报
```

按用户时区和消息时间筛选，避免漏掉昨天创建、今天继续工作的会话。范围确定后简短说明使用了哪些项目或会话。来源不完整时说明限制，不凭会话标题或 ID 猜测成果。

会话中的工作只覆盖被记录的部分；线下工作可由用户补充。涉及敏感信息时，根据受众省略密钥、个人信息和不必要的内部细节。

## 定时生成

向支持调度的宿主提出，例如：

```text
每个工作日18:00，用 Daytrace 汇总当前项目当天的工作。
时区 Asia/Shanghai，使用团队日报模板，保存为日报草稿。
```

首次设置保存范围、时区、模板和输出位置，每次运行重新查找当天相关会话。需要读取本地文件的调度任务须满足宿主的运行条件与文件权限。生成草稿不会自动授权对外发送。

## 当前能力与限制

Daytrace 当前是**指令型 skill**，包含工作流程与写作规范，没有独立日志解析器、模型服务或后台调度程序。

| 能力 | 条件 |
|---|---|
| 按模板整理与写作 | agent 能读取 skill 和工作记录 |
| 当前会话总结 | agent 能访问当前上下文 |
| 跨会话发现与汇总 | 宿主提供会话列表、读取工具或日志权限 |
| 截图模板 | 宿主模型具备图像理解能力 |
| 定时生成 | 宿主提供可用调度器 |

已在 Codex 会话场景中迭代使用；skill 结构校验通过。通用指令不等于所有平台已验证兼容，也不保证能够读取完整历史。欢迎贡献其他宿主的适配方法与可复现案例。
